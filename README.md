# JetSeat XInput Bridge

Прокси-библиотека XInput для вибронакидки **Gametrix JetSeat KW-901**, которая
позволяет использовать накидку в современных играх, для работы требуется оригинальный
драйвер от производителя.

Библиотека подменяет `xinput1_3.dll` (или `xinput1_4.dll`) в папке с игрой,
перехватывает вызовы вибрации геймпада, транслирует их в COM-интерфейс
`IUberwoorf` и передаёт на JetSeat. Реальный геймпад при этом продолжает
работать штатно — вибрация на нём сохраняется.

## Как это работает

```
Игра
  │
  ├─► XInputSetState(left, right)
  │        │
  │        ▼
  │   [JetSeat XInput Bridge]
  │        ├─► Проброс на системную XInput → реальный геймпад вибрирует
  │        │
  │        └─► Стерео-маппинг → 6 зон JetSeat
  │                 │
  │                 ▼
  │           [uwapi.dll / драйвер Gametrix]
  │                 │
  │                 ▼
  │           [Gametrix JetSeat KW-901]
```

1. Игра загружает `xinput1_3.dll` из своей папки вместо системной.
2. Подменная DLL перехватывает `XInputSetState` и пробрасывает вызов в системную
   библиотеку — геймпад работает как обычно.
3. Дополнительно значения левого и правого моторов транслируются в шесть зон
   JetSeat (ноги, поясница, спина) через официальный драйвер
   `uwapi.dll`.
4. Вибрация на накидке соответствует игровым событиям без задержек.

## Маппинг вибрации

Используется **стерео-маппинг по разнице каналов**:

| Составляющая сигнала | Куда идёт |
|---|---|
| Симметричная (левый ≈ правый) — общие толчки, взрывы, тряска | Поясница и спина |
| Асимметричная (левый ≠ правый) — боковые удары, занос | Нога соответствующей стороны |

Такое распределение даёт «пространственные» ощущения: фронтальные события
чувствуются в спине, боковые — в ногах. Амплитуда каждой зоны
пропорциональна значению XInput (0–65535 → 0–255).

## Установка

1. Скачай `JetseatXinput.dll` из раздела — выбери
   разрядность, совпадающую с разрядностью игры (Win32 для 32-битных игр,
   x64 для 64-битных).
2. Скопируй DLL в папку с `.exe` игры.
3. Переименуй DLL в Xinput1_3.dll, чтобы игра её воспринимала. Для разных игр
   могут потребоваться другие имена например: xinput1_1.dll, xinput1_2.dll, xinput1_4.dll, xinput9_1_0.dll.    
5. Запусти игру. JetSeat должен вибрировать в такт игровым событиям.

Если игра использует `xinput1_4.dll` (некоторые современные игры), переименуй
DLL в `xinput1_4.dll` и положи в ту же папку. Для `xinput1_4.dll` может потребоваться
другой `.def`-файл — см. раздел «Сборка».

### Проверка работы

Рядом с DLL создаётся файл `jetseat_log.txt`. При успешной инициализации в нём
будут строки:

```
[DllMain] PROCESS_ATTACH
[InitThread] Started
[LoadSystemXInput] LoadLibraryW OK
[Resolve] SetState OK
[InitJetSeat] CoCreateInstance OK
[InitJetSeat] uwOpen OK
[InitJetSeat] DONE
```

Если лог не создаётся или обрывается — см. раздел «Диагностика».

## Совместимость

**Работает:**

- Офлайн-игры без античита с поддержкой Xinput.

**Не работает:**

- Игры с античит-системами (EAC, BattlEye, встроенные защиты).
- Игры из Microsoft Store / Xbox App — защищённая папка `WindowsApps`
  блокирует подмену DLL.

> ⚠️ **Внимание:** Попытка загрузить библиотеку в игру с античитом может
> привести к бану аккаунта или HWID. Не используйте в онлайн-играх.

## Требования

- Windows 10 или 11.
- Установленный драйвер **Gametrix JetSeat** (включая `uwapi.dll` и
  зарегистрированный COM-объект `CLSID_Uberwoorf`).
- Visual Studio 2019/2022 с workload «Desktop development with C++»
  (только для сборки из исходников).

## Сборка из исходников

### Шаги

1. В **Property Pages → C/C++ → Code Generation → Runtime Library**
   установи **Multi-threaded (/MT)**.
2. В **Property Pages → Linker → Input → Module Definition File** укажи
   `xinput1_3.def` (или `xinput1_4.def` для сборки под 1.4).

## Диагностика

### Лог не создаётся

1. **Проверь разрядность.** 32-битная игра требует `xinput1_3.dll` (Win32),
   64-битная — x64. Несовпадение разрядности — самая частая причина.
2. **Проверь путь через Process Monitor.** Запусти ProcMon с фильтрами:
   - `Process Name is <имя игры>.exe`
   - `Operation is Load Image`
   - `Path contains xinput`
   Убедись, что игра загружает DLL из папки с игрой, а не системную
   из `System32`.
3. **Антивирус.** Некоторые антивирусы блокируют загрузку неподписанных DLL.
   Добавь папку игры в исключения.
4. **Права на запись.** Если игра не может писать лог в свою папку, `Log`
   молча ничего не запишет. Проверь права на папку.

### Лог создаётся, но нет `[InitJetSeat] DONE`

- **`CoCreateInstance failed`** — драйвер JetSeat не установлен или COM-объект
  `CLSID_Uberwoorf` не зарегистрирован. Проверь через
  `Get-Item "HKLM:\SOFTWARE\Classes\CLSID\{22420DBA-2927-4d71-B6B8-028982A62B72}"`.
- **`uwOpen failed`** — устройство занято другим приложением (SimShaker,
  irFFB) или не подключено.
- **`SetVibration hr=0x80070057`** — неверные аргументы; `uwapi.dll` требует
  минимум две точки в паттерне вибрации и ненулевую длительность.

### Вибрация есть, но слишком слабая/сильная

Отрегулируй `AMP_THRESHOLD` в `jetseat_bridge.cpp` — порог, при котором
обновление отправляется драйверу. Значение 3 (из 255) даёт плавную вибрацию;
увеличение до 7–10 сглаживает мелкие колебания.

## Известные ограничения

- **Игры с античитом.** См. раздел «Совместимость».
- **COM-объект только 32-бит.** Если 64-битной версии `uwapi.dll` нет в
  системе, JetSeat не заработает в 64-битных играх.
- **Только первый геймпад.** Обрабатывается `dwUserIndex == 0`.
- **Только 6 зон.** JetSeat имеет 6 моторов; другие виброустройства
  (ButtKicker и т.п.) не поддерживаются.
